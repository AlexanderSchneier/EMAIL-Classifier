Project Title: Smart Multi-Class Email Classification Using Machine Learning and Natural
Language Processing.
Team Members: Upi Shanker and Alexander Schneier
Introduction and Motivation
Email remains one of the most widely used communication tools in both personal and
professional environments. Despite advances in email filtering technologies, users continue to
face challenges caused by the increasing volume and diversity of incoming emails. In addition to
spam and phishing messages, inboxes are frequently flooded with promotions, social
notifications, financial updates, and work-related correspondence. Traditional email filtering
systems primarily focus on binary classification, separating spam from legitimate emails, which
is insufficient for effective inbox organization in modern settings. This project seeks to address
this limitation by developing a machine learning based system capable of automatically
categorizing emails into multiple meaningful classes using both metadata and textual content.
By moving beyond simple spam detection, the proposed system aims to improve usability,
productivity, and security in real-world email environments.
Research Question
The primary research question of this project is whether machine learning models trained on
email metadata and textual content can effectively classify emails into multiple meaningful
categories while maintaining high accuracy and robustness. In particular, the project
investigates how different feature types, including subject lines, sender information, and email
body language, contribute to classification performance. Additionally, the study examines
whether models trained on publicly available spam datasets can generalize effectively when
extended to a newly created dataset with more fine-grained labels.
Literature Survey
Email classification has been extensively studied, especially in the context of spam and phishing
detection. The work titled A Comprehensive Survey for Intelligent Spam Email Detection
presents a detailed overview of the transition from rule-based filtering methods to machine
learning approaches such as Naive Bayes, Support Vector Machines, and ensemble models.
These methods have consistently demonstrated strong performance in binary spam detection
tasks. Phishing email detection has also received significant attention due to its cybersecurity
implications. Studies such as A Systematic Literature Review on Phishing Email Detection
Using Natural Language Processing Techniques and Phishing Email Detection Using Natural
Language Processing Techniques: A Literature Survey emphasize the effectiveness of natural
language processing methods, including n-gram modeling, TF-IDF feature extraction, and
semantic analysis, for identifying malicious emails. More recent research has explored
multi-class email sorting systems, as seen in Automated Email Sorting in Organizations: A
Machine Learning based Multi-Class Classification System. These works demonstrate the
feasibility of automatically categorizing emails into functional classes using supervised learning
techniques. However, many existing approaches rely on fixed datasets and do not evaluate
model performance on newly collected or user-labeled data. This project addresses this gap by
combining benchmark datasets with a custom-labeled dataset to assess adaptability and
generalization in real-world scenarios.
Algorithms and Methods
The project will be implemented in Python using standard data mining and machine learning
libraries. Several classification models will be explored, starting with baseline methods such as
Naive Bayes and Logistic Regression to establish reference performance. More advanced
traditional machine learning models, including Support Vector Machines and Random Forests,
will be implemented to improve classification accuracy. In addition, deep learning approaches
will be explored using neural networks and transformer-based text embeddings to capture
contextual information from email content. Feature extraction will incorporate information from
email subject lines, sender metadata, and email body text. Textual features will be represented
using techniques such as TF-IDF, n-grams, and contextual embeddings, while sender-related
features will include domain information and frequency-based indicators.
Expected Experiments and Datasets
Experiments will be conducted using both public and custom datasets. Publicly available
datasets such as the Enron Spam Dataset and SpamAssassin will be used for initial training
and evaluation of spam classification models. To extend the task beyond binary classification, a
new dataset will be created by manually labeling emails into multiple categories, including
spam, phishing, promotions, social or notification emails, and personal or work-related
messages. Experimental evaluation will compare binary and multi-class classification
performance across different models and feature sets. Performance will be measured using
accuracy, precision, recall, F1-score, and confusion matrix analysis. Additional experiments will
analyze the impact of individual feature types and test the model’s ability to generalize across
datasets.
Novelty, Necessity, and Preliminary Results
The novelty of this project lies in its integration of public benchmark datasets with a newly
created, fine-grained labeled dataset, allowing for evaluation of real-world adaptability rather
than performance on a single static dataset. While many existing studies focus solely on spam
or phishing detection, this project emphasizes multi-class classification and feature-level
interpretability. Preliminary experiments conducted using a Naive Bayes classifier on a public
spam dataset achieved an accuracy of approximately ninety-five percent in binary spam
detection. Qualitative analysis of misclassified emails suggests that incorporating contextual text
embeddings and sender-based features can further improve classification performance,
motivating the proposed multi-feature, multi-model approach.
Project Timeline
The project will begin with a literature review and dataset selection during the first two weeks.
Data preprocessing and feature extraction will be conducted in the third week, followed by
baseline model implementation in weeks four and five. Advanced machine learning and deep
learning models will be developed in week six. The custom dataset will be created and labeled
during week seven, and comprehensive experimental evaluation and analysis will be performed
in week eight. The final report and presentation materials will be prepared and submitted in the
final week of the project timeline.
